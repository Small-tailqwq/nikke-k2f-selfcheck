# NIKKE K2F 露出範囲セルフチェック

NIKKE Launcher のサプライチェーン攻撃で見つかった K2F サンプルの収集リストをもとに、対象の場所がこのコンピューターにあるかを確認し、ブラウザーに保存されたパスワードと Cookie の暗号化方式を集計して、ローカルの HTML レポートを作成します。

場所が存在しても、データが読み取られたり送信されたりしたとは限りません。このツールは感染を検出せず、漏えいの有無も確認できません。K2F の実行痕跡は [Sheisback/nikke_malware_scanner](https://github.com/Sheisback/nikke_malware_scanner) で確認してください。

## ダウンロード

[Releases](https://github.com/Small-tailqwq/nikke-k2f-selfcheck/releases) から `k2f-selfcheck.exe` をダウンロードし、ダブルクリックで実行します。レポートは exe と同じフォルダーに保存され、既定のブラウザーで開きます。

exe はこのリポジトリのソースから GitHub Actions でビルドしています（PyInstaller の単一ファイル）。一緒に公開している `.sha256` ファイルで検証できます。

```powershell
Get-FileHash .\k2f-selfcheck.exe -Algorithm SHA256
```

PyInstaller で作った実行ファイルは、一部のウイルス対策ソフトで誤検知されることがあります。気になる場合はソースから実行してください。

## ソースから実行

Windows 10/11 と Python 3.11 以上が必要です。追加のインストールは不要です。

```powershell
python k2f_selfcheck.py
```

ソースから実行する場合、レポートは既定でスクリプトのフォルダーに保存されます。`--out` の相対パスは起動時の作業フォルダーを基準とし、絶対パスは指定の場所に保存します。

| オプション | 用途 |
|---|---|
| `--lang` | レポートと出力の言語：`zh`、`en`、`ja`、`ko`。既定は Windows の表示言語に合わせ、それ以外の言語では英語になります |
| `--out` | レポートのパス（`.html` または `.htm`）。既存のファイルは上書きしません |
| `--no-open` | レポートを保存するだけで、ブラウザーは開きません |
| `--quick` | Chromium のデータベースとウォレットを省略し、他の対象は確認します |
| `--no-browser-count` | ブラウザーのデータベースを省略します |
| `--targets` | 使用するターゲットリスト。既定はスクリプトと同じフォルダーの `k2f_targets.json` |

終了コード `0` はレポート作成の成功、`2` は実行環境、入力、書き込みのいずれかの失敗を示します。終了コードは感染や漏えいの状態とは関係ありません。

## レポートの内容

レポートを開くと最初に説明が表示され、「確認しました」ボタンは 6 秒後に押せるようになります。本文は、概要、ブラウザーデータ、認証情報の場所、ウォレット拡張機能、未完了の確認、説明の順です。

- **v10：高リスク。** 現在のユーザー権限で動くプログラムなら復号できます。サイトごとにパスワードを変更し、他の端末からサインアウトし、二段階認証を有効にしてください。
- **暗号化されていない Cookie：サンプルの読み取り対象外。** サンプルは `encrypted_value` を取得します。`value` のみの記録は別に表示し、このサンプルの高リスク項目には数えません。
- **不明な形式：** 保護方式を判断できないため、v10 と同様に対処してください。
- **v20：低め。** アプリバインド暗号化で保護されており、復号には管理者権限かブラウザープロセスへの注入が必要です。v10 の対処を終えたら、重要なサイトからサインアウトしてください。
- **認証情報の場所：** 存在する設定ファイル、認証情報ファイル、鍵フォルダーをツール別に示し、それぞれの更新方法を記載します。プログラムフォルダーと一般のユーザーフォルダーは別にまとめ、認証情報の場所には数えません。

件数は記録数またはターゲットのテンプレート数で、漏えいした認証情報の数ではありません。

詳細では、パスワードは記録ごとにサイト、マスク済みのアカウント、ブラウザーを、Cookie はサイトごとの件数を表示します。長いリストは固定の行の高さでブロックに分けて描画し、画面外のブロックはブラウザーが描画を省くため、数万件の記録でもすぐに展開できます。レポートにスクリプトは含まれず、外部リソースも読み込みません。

## 確認範囲とプライバシー

- 通常の対象はパスとファイルのメタデータのみ確認します。プロジェクト設定、Firefox の `key4.db` / `logins.json`、GPG 鍵ファイル、`KUBECONFIG` が指すファイル、NIKKE の認証情報ファイルも確認しますが、秘密情報の内容は読み取りません。
- プロジェクト検索は深さ 2 までとし、`.git` / `node_modules` および `.example` / `.sample` / `.template` ファイルを除外します。SSH 設定と PuTTY / WinSCP セッションは、外部の鍵ファイルの参照先とパスワード欄の有無の確認に使います。
- プロセスとユーザー／システムレジストリの環境変数をサンプルの規則で選別し、レポートには変数名だけを残します。Windows 資格情報マネージャーは項目数のみ取得します。環境変数の値、認証情報の内容、実際のカスタムパスは記録しません。
- Chromium データベースは共有読み取り専用でメモリに読み込み、暗号化の接頭辞を識別します。復号や元ファイルへの書き込みは行いません。Chrome、Edge、Brave、Vivaldi、Opera の既知のルート配下にある全プロファイルディレクトリを確認します。Opera ルートのデータベースと既知のルート外のポータブル版は対象外です。ウォレットは Chrome のみで、拡張機能のインストールと対応するコンテナー内の `.ldb` / `.sst` / `.log` ファイルを確認します。
- ブラウザーの詳細はサイトのホスト名、プロファイル番号、マスク済みアカウントのみ残します（4 文字以下は全て、それ以外は先頭と末尾以外を隠します）。URL のパスやパラメーター、パスワード、Cookie の名前と値、トークン、秘密鍵は含みません。サイト一覧と環境変数名も個人情報なので、レポートは公開しないでください。
- ネットワークパス、ネットワークドライブ、再解析ポイントは除外します。未設定の環境変数は対象外、サンプルの上限 4 MiB を超えるブラウザーファイルはサンプルによるスキップと表示します。読み取り失敗は未完了のまま残します。未マージの WAL がある場合はメインファイルだけを集計し、不完全と表示します。

対象パスと検出規則は K2F LuaJIT バンドル（SHA-256 `cc0ad05bfe85940a6067b3a72c182d3953339129206634141926d5d0b35973ec`）の静的解析に基づきます。ファイルの存在は保存先の候補を示すもので、設定・履歴・セッション内容の抽出や復号は再現しません。
